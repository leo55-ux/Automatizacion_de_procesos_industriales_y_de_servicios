DIAGRAMA ELÉCTRICO — SISTEMA DE CONTROL DE INVERNADERO ARDUINO UNO
sensor de humedad del suelo

Alimentado desde la protoboard (VCC/GND) con su salida de datos hacia un pin analogico del Arduino.

Pantalla LCD 16×2 I2C

VCC, GND, SDA y SCL conectados directamente a Arduino para mostrar las lecturas.

Módulo relé de 2 canales

IN1 e IN2 reciben la señal de control de Arduino; alimentado con 5V externos.

Bomba de agua 5V

Conmutado por el canal 2 del relé, alimentado por la misma fuente externa de 5V.

Código para el invernadero

Sketch de Arduino que implementa el ciclo medir → decidir → actuar: lee el sensor de humedad del suelo,actia la bomba de agua y muestra los datos en el LCD.

invernadero_inteligente.ino 
//L3.0
//incluimos las ibrerias que se utilizaran

#include <Wire.h>
#include <LiquidCrystal_I2C.h>

LiquidCrystal_I2C lcd(0x27,16,2);
int bomba_agua=7;
void setup(){
  pinMode(bomba_agua,OUTPUT);
  lcd.init();
  lcd.backlight();
  lcd.clear();
}


void loop(){
 int valor=analogRead(A0);
    lcd.setCursor(0,0);
    lcd.print("HS:");
    lcd.print(valor);
  if(valor<30){
    digitalWrite(bomba_agua,HIGH);
  	}
  
  else{
  digitalWrite(bomba_agua,LOW);
  }
  delay(1000);
}
